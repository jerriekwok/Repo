# 厨房模拟游戏 (Kitchen Simulation Game)

## 项目概述
这是一个基于Unity引擎开发的3D厨房模拟游戏(通过学习CodeMonkey的视频完成的demo)，玩家在游戏中扮演厨师角色，进行食材处理、烹饪制作和菜品组合等操作。游戏采用了现代化的Unity开发技术和设计模式，具有良好的可扩展性和维护性。

## 技术栈
- **游戏引擎**: Unity 2021.3 LTS
- **开发语言**: C#
- **输入系统**: Unity New Input System
- **UI系统**: Unity UI + TextMesh Pro
- **数据管理**: ScriptableObject + PlayerPrefs
- **版本控制**: Git

## 部署说明
PS: 由于打包出的文件过大 无法上传 需要自行下载unity部署
### 环境要求
- Unity 2021.3 LTS 或更高版本
- .NET 6.0 SDK 或更高版本
- Git

### 安装步骤 
1. **克隆仓库**
2. **打开项目**
   - 启动Unity Hub
   - 点击"Add"按钮，选择项目文件夹
   - 选择对应的Unity版本（2021.3 LTS）
   - 点击"Open"按钮打开项目

3. **导入依赖**
   - 项目首次打开时，Unity会自动导入所需的包和资源
   - 等待导入完成（可能需要几分钟时间）

4. **构建项目**
   - 选择"File" -> "Build Settings"
   - 选择目标平台（Windows、Mac或Linux）
   - 点击"Build"按钮，选择输出目录
   - 等待构建完成

## 运行说明

### 开发环境运行
1. 确保已完成上述安装步骤
2. 在Unity编辑器中打开项目
3. 选择"Assets/Scenes/"目录下的主场景
4. 点击播放按钮（▷）开始游戏

### 发布版本运行
1. 确保已完成构建步骤
2. 打开构建输出目录
3. 双击可执行文件（.exe或.app）
4. 开始游戏

## 游戏控制

### 键盘控制
- **移动**: WASD或方向键
- **交互**: E键
- **特殊交互**: F键（如切割食材）
- **暂停**: ESC键

### 游戏手柄控制
- **移动**: 左摇杆
- **交互**: A键（Xbox）/ X键（PlayStation）
- **特殊交互**: X键（Xbox）/ □键（PlayStation）
- **暂停**: Start键（Xbox）/ Options键（PlayStation）

### 自定义键位
游戏支持自定义键位设置，在游戏暂停菜单中可以进行键位映射调整。

## 功能介绍

### 核心功能
- ✅ 玩家移动与旋转控制
- ✅ 多种食材和厨房物品
- ✅ 食材处理（切割、烹饪等）
- ✅ 菜品组合与制作
- ✅ 游戏状态管理（开始、暂停、结束）
- ✅ 倒计时和时间限制
- ✅ 自定义键位设置

### 特色系统
- **模块化架构**: 清晰的模块划分，便于扩展和维护
- **事件驱动**: 使用C#事件系统实现组件间通信
- **数据驱动**: 使用ScriptableObject管理游戏数据
- **状态机**: 实现游戏状态的有序切换

## 项目结构

```
Assets/
├── Prefabs/           # 游戏预制体
├── Scripts/           # 游戏脚本
└── ScriptableObject/  # 游戏数据定义
```
